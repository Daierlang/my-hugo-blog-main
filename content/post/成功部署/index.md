折腾了好些天，博客总算成功部署了。值得一提的是，手机端适配有了惊喜 ——Stark 主题似乎做了不少优化，浏览体验顺畅了很多。不过后续还有一堆待办事项要慢慢理顺：

首先得系统学习下 Markdown 语法，毕竟写文章离不开它；其次，目前用的编辑器试用期快到了，得赶紧找个合适的替代工具；再者，自动部署的流程还没打通，这一步必须搞定才能提高效率。

另外，关于 GitHub 的文件更新上传和 Hugo 的基础操作，也得再巩固一下：

- 生成 public 文件：`hugo -D`
- 本地预览效果：`hugo server -D`（之前输错成 serrver 了，修正下）
- 创建新文章：`hugo new content 路径/文件名/index.md`
- 上传到 GitHub 的步骤：`git init`初始化仓库 → `git add .`添加所有文件 → `git commit -m"本次更新说明"`提交更改 →git branch -M main  > `git push -u origin main`推送（如果推送失败，可尝试用`-f`强制推送，但注意强制推送可能覆盖远程内容，谨慎使用）

除了这些基础操作，还有几个美化和功能优化的方向：换一张更贴合博客风格的背景图；给文章添加合适的图片，让内容更生动；完善分类和归档功能，方便读者查找内容；最后，得把评论系统加上，增加和访客的互动性。

一步一步来，慢慢把博客打磨得更完善些～
