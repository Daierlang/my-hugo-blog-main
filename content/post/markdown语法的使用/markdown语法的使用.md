## [^2]正文markdow语法
#### 标题部分
```
# 一级标题     （这样表示一级标题，后面以此类推，最高能到六级标题）
## 二级标题
### 三级标题
...........
```
直接这样打出来回车就是，#和空格便被归入源码隐藏，我们想要看到被隐藏这部分可以在设置里打开源码模式，就能看到markdown语法的部分。（obsidia在右上角三个点）
普通文本编辑器中直接这样表示就行。
通过大纲我们可以浏览标题，和文章的整体结构。（obsidia点击右上角展开选项）

#### 字体部分
```
**hello** 表示粗体 或用ctrl+i
*hello*   表示斜体 或用ctrl+b
***hello***   表示斜体加粗体
~~hello   给文字加删除线
```
#### 引用

###### 文本引用
```
> 引用的内容
```
###### 图片引用
```
![图片名称](图片路径本地或者网络图片)      注意用英文符号
```
关于网络图片，在浏览器右键图片点击审查元素，复制地址就行，带jpg的（好像填了路径也有不显示，不过这里可以直接复制图片再粘贴也许行，然后是茜,图片好像不能正常显示，不过本地是可以的）![xi](static\favicon.ico)


###### 超链接
```
[标题](地址)
```

###### 快捷复制内容
	直接用tab再输入内容就行，它会把文字放进一个小灰框，右上角提供一个复制按钮，
	就像这样。好像这里并没有显示复制，不过本地是有的。

#### 分割线
```
---     有这两种写法
***
```
#### 列表
```
有序列表      如删除内容2，内容3会自动修改序号为2.
1 内容
2 内容
3 内容

无序列表
- 内容        用一个点放内容前面
```

#### 表格
一般是直接用编辑器插入就行简单，源码如下
```
|a|b|c|      注意中间不要空行，通过打开源码模式可以看看中间有没有行
|--|--|--|
|A|B|C|
```

## [^3]关于obsidian的使用

1. 当我们初次完成安装时，首先需要创建一个仓库存放我的内容
2. 当光标停留在选项上时它会显示选项名称。
3. 文件列表->新建笔记，就能开始写作了。
或直接快捷键，ctrl+n，就能开始写作了。
4. 左键长按框选后右键或直接右键，可以看到对应前面markdown语法操作。
5. 当你不需要左边这一块时，直接点击最左上角收起，右边同理也可以展开或收起。
6. 我们在编写完成后点击右上角，从书图标切换到笔图标，即从编写切换到预览，哦们可以确认效果排版对不对。

odbsidian特别点，最左，往下第第二，关系图谱，便于你像存储文件一样管理和查阅，不过这得你记的多才能看到效果。
