要写新的 Hugo 博客，步骤如下：

步骤 1：进入 Hugo 项目根目录
打开命令行终端（如 Windows 的 CMD、PowerShell，或 Git Bash），切换到你的 Hugo 项目根目录（比如你的项目在 E:\huge\quickstart，就执行 cd E:\huge\quickstart）。

步骤 2：创建新文章（自动生成模板）
执行 Hugo 命令生成新文章草稿：

hugo new posts/我的新博客.md

这会在 content/posts/ 目录下，生成一个名为 我的新博客.md 的文件；
文件里会自动包含Front Matter（文章头部的配置，比如标题、日期、是否为草稿等）。

也可以直接在 content 目录（或其子目录，比如 content/posts/）里手动创建文件夹和 .md 文件，但是需要手动配置一下front matter。

步骤 3：编写文章内容
用任意文本编辑器（如记事本、VS Code、Typora这个付费）打开 content/posts/我的新博客.md，在 --- 分隔的 Front Matter 下方，编写文章内容（支持 Markdown 格式）。

示例（Front Matter 不用动，下方加内容）：
md
---
title: "我的新博客"
date: 2025-11-01T12:00:00+08:00
draft: true  # 此时是“草稿”状态，预览需加 -D 参数
---

# 这是我的新博客标题

这里写文章内容...可以用 **Markdown 格式** 排版。

关于时间格式，这个日期格式是ISO 8601 标准格式，拆开来理解很简单：
2025-11-01：表示年 - 月 - 日（2025 年 11 月 1 日）；
T：是 “时间（Time）” 的分隔符，用来区分日期和时间；
10:00:00：表示时：分: 秒（上午 10 点 0 分 0 秒）；
+08:00：表示时区偏移（东八区，即北京时间，比 UTC 时间快 8 小时）。

步骤 4：本地预览文章
启动 Hugo 本地服务器，预览文章（因为 draft: true，需加 -D 显示草稿）：
bash
hugo server -D 
然后打开浏览器，复制cmd里面的链接到浏览器（也可以按住ctrl然后左键直接访问），就能看到新文章出现在列表里～

步骤 5：发布文章
如果文章写完，想 “正式发布”（不再是草稿），只需把文章里的 draft: true 改成 draft: false，再重启 Hugo 服务（或直接用 hugo server 不带 -D），文章就会永久显示啦～（这部分是针对有供外部访问的朋友的）


关于markdown语法这部分

Markdown 是一种**非常简单的“文字排版语法”**，只需要在文字前后加一些符号，就能实现标题、加粗、列表、链接等排版效果。下面用最常用的格式举例子，你一看就懂：

### 1. 标题
用 `#` 号表示，`#` 越多，标题级别越低：
```markdown
# 一级标题（最大）
## 二级标题
### 三级标题
#### 四级标题
```f


### 2. 加粗 & 斜体
- 加粗：文字前后加 `**`
- 斜体：文字前后加 `*`
- 加粗+斜体：文字前后加 `***`

示例：
```markdown
**这是加粗的文字**
*这是斜体的文字*
***这是又加粗又斜体的文字***
```


### 3. 列表
- 无序列表：用 `-` 或 `*` 开头
- 有序列表：用 `数字.` 开头

示例：
```markdown
- 无序列表项1
- 无序列表项2
  - 子列表项
* 无序列表项3

1. 有序列表项1
2. 有序列表项2
   1. 子列表项
```


### 4. 链接 & 图片
- 链接：`[显示的文字](网址)`
- 图片：`![图片描述](图片地址)`（和链接类似，前面多一个`!`）

示例：
```markdown
[点击跳转到百度](https://www.baidu.com)
![一张风景图](https://example.com/风景.jpg)
```


### 5. 引用
用 `>` 开头，适合引用别人的话或段落：
```markdown
> 这是一段引用内容，比如名人名言~
```


### 实战示例（写一篇简单的博客）
把这些格式组合起来，一篇博客就出来了：
```markdown
---
title: "我的第一篇Markdown博客"
date: 2025-11-01T10:00:00+08:00
draft: false
---

# 欢迎来到我的博客

**今天我学会了Markdown格式！** 它真的很简单：

- 用 `#` 写标题
- 用 `**` 加粗文字
- 还能插入链接：[点击去Hugo官网](https://gohugo.io)

> 总结：Markdown让写博客变得超轻松~
```


只要记住这些基础符号，就能快速写出排版美观的博客啦！
